# Changelog

## Polish v2 — 2026-09-26

### Flight handling
- Increased roll authority and maximum bank envelope.
- Increased yaw response and ground steering authority.
- Increased bank-to-heading turn response.
- Smoothed the roll transition so the aircraft does not visually snap into a bank.

### Airport traffic
- Reduced parked and airborne NPC density.
- Reduced the number of aircraft pre-seeded into the departure queue.
- Increased taxi, line-up, takeoff, approach, rollout, and taxi-in speeds.
- Reduced runway separation cooldown and NPC turnaround delays.
- Retained ATC sequencing, runway occupancy logic, yielding, and collision checks.

### World
- Added more varied terrain relief/ridges/coves.
- Improved terrain colour bands and small-scale surface variation.
- Reworked foliage placement so Coral Bay receives proper vegetation/detail.
- Expanded cloud coverage across the route and added subtle drift.

### Interface
- Refined the launch panel into a compact glass-style card.
- Reduced visual weight of the top bar and secondary HUD panels.
- Tightened quick-start controls and spacing.
- Added responsive cleanup for narrower screens.

## Visual hotfix v3
- Fixed the ugly dark apron/terminal artefacts by softening shadows and stopping thin runway/apron slabs from receiving harsh shadow acne.
- Improved the ready-screen camera framing so the airport preview looks closer and less flat.
- Reduced oversized in-world labels for terminals/taxiway signage.
- Moved the navigation panel away from the main start card for a cleaner menu layout.
