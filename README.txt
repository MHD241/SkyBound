Skybound 3D Flight Simulator - downloadable deployed build

How to host:
1. Upload everything in this folder to the root of your hosting site.
2. Keep the _next folder beside index.html.
3. Open index.html through a web server, not by double-clicking the file.

Important:
- This is the exact deployed production bundle mirrored from the Skybound site.
- The game expects to be hosted from the domain root because the built files use /_next/... paths.
- If your host puts it inside a subfolder, use a root-level deployment or configure redirects so /_next/static/... points to this package's _next/static folder.
